# Ashlar

A tile home screen for Android. Pins, a few tile sizes, an A–Z app list,
and three looks: flat, glass frame, and liquid glass.

Releases: https://github.com/wilsonsamiano/ashlar/releases

The package id stays `com.wilson.win10launcher` so an update installs over
the copy you already have. Tiles and settings stay.

## Install

Install the release APK over the launcher you have. Do not uninstall first.
The home app will show up as **Ashlar**.
